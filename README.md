- ชี้ตัวถูก: ตำรวจดีได้ผลงานช่วยเลื่อนยศ ถ้าคนร้ายมีคนหนุนหลังต้องเลือกส่งฟ้อง/ปล่อยข่าว/รับซอง · ตำรวจเลวเลือกส่งชื่อให้เฮียเส็ง รีดเงิน หรือเตือนให้หนี
- ชี้ผิดตัว: ตำรวจดีจับแพะ (บาป ความสุขลด อาจถูกยกฟ้องและพักเลื่อนยศ) · ตำรวจเลวทำให้คนบริสุทธิ์หายตัวและความร้อนแรงเพิ่ม · ฉากจบใหม่ 3 แบบ
- Billionaire Club: ไม่ใช่การสอบศีลธรรม ทุกดีลมีตัวเลือก "ทุ่มหมดหน้าตัก" · ธนกรคู่แข่งในคลับเลื่อยขาได้ทั้งดีลสุจริตและทุจริต ก่อนรู้ผลจะมีเหตุพลิก 6 แบบ (ข่าวลือ ซื้อตัวซีอีโอ จดหมายถึงผู้กำกับ ภาพจัดฉาก ผู้ร่วมทุนถอนตัว ตลาดดิ่ง) ให้เลือกตอบโต้แบบสุดโต่ง · ยิ่งชนะ ความแค้นยิ่งสูง ถึง 70 จะเกิดสงครามกับธนกร (เทคโอเวอร์ / เผาแฟ้มลับ / สงบศึก / ไม่ตอบโต้) · ฉากจบใหม่ "ผู้กลืนคู่แข่งทั้งโต๊ะ" และ "คนที่ถูกเลื่อยขาจนตกโต๊ะ"

## อัปเดต: โรงเรียนเวทมนตร์ภาคใหม่ — ความรัก คู่แข่ง สาวกเงา และราหุลกาฬ (story v4)

- ตัวละครหลักสามคน เลือกเพศได้ตอนเข้าเรียน (เพศตรงข้าม / เพศเดียวกัน / สุ่ม / คลาสสิก): คู่กัดผมสีทองตระกูลอัครเดชา (ธาวิน/ธารินทร์) · เพื่อนสนิทคนแรก (ปลายฟ้า/ปลายฝน) · ดาวโรงเรียน (รวิภา/รวิศ)

## อัปเดต story v5 — สืบสวนและความรักในโรงเรียนเวทให้เข้าใจง่ายขึ้น

- **กระดานสืบสวนแบบการ์ด**: บอกเป้าหมายชัด ๆ (หาสาวกที่ตรงกับเบาะแสทุกข้อ) ผู้ต้องสงสัยแต่ละคนเป็นการ์ด ลักษณะที่ตรงกับเบาะแสขึ้น ✔ สีเขียว ไม่ตรงขึ้น ✘ สีแดงและการ์ดถูกตัดออก มีตัวนับว่า "ยังน่าสงสัย N คน"
- ใต้ตัวเลือกตามเบาะแสบอกล่วงหน้าว่าเบาะแสนั้น **ช่วยตัดใครได้หรือไม่** และหลังได้เบาะแสจะแจ้งว่าตัดใครออกไป
- แฟ้มลับของอาจารย์มณีจันทร์อธิบายกติกา: สืบตอนอายุ 12/14/16, ชี้ตัวตอน 17, ผลของการชี้ถูก/ผิด
- หน้าชี้ตัว: แต่ละชื่อบอกว่าตรงกับเบาะแสทุกข้อ หรือไม่ตรงข้อไหน
- **การ์ดความรัก**: หัวใจ ❤ /10, สถานะความสัมพันธ์, คู่แข่ง, สิ่งที่รู้ว่าเขาชอบ/ไม่ชอบ, สรุปบทที่แล้ว และหัวข้อ "บทรัก n/5"
- หน้าเลือกคนรักอธิบายว่าเส้นเรื่องรักทำงานอย่างไร พร้อมประวัติย่อของทั้งสามคน
- **มินิเกมเดต** (ชีวิตใหม่/ตัวเลือกถัดไปหลังอัปเดต): เลือกที่เดตจากคำใบ้ ถูกใจ +3 หัวใจ, เฉย ๆ +1, ไม่ชอบ −1 และเกมจำสิ่งที่ค้นพบไว้ให้เดตครั้งต่อไป
- เซฟ: เพิ่ม `storyV5From`; การ์ดใหม่แสดงผลกับทุกชีวิตทันที ส่วนเดต (หน้าจอใหม่) เริ่มนับจากตัวเลือกที่ยังไม่ได้เล่น เซฟเก่า replay ได้เหมือนเดิม

- ฉากใหม่วัยเรียน: ไม้กวาดลายมังกรทอง (8) · จดหมายตรามังกรทองจากพ่อ (11) · มังกรน้อยในหอคอยร้าง (13) · คำสั่งให้ขโมยสมุดสืบสวน (15) · หลังคาหอคอยคืนก่อนจบการศึกษา (18)
- ฉากใหม่วัยทำงาน: ประมุขคนใหม่แห่งอัครเดชา (22) · มังกรทองตื่น (38: ถ้าเป็นมิตรได้ขี่มังกรด้วยกัน ถ้าเป็นศัตรูต้องหยุดมังกรที่เผาเมือง) · ศึกชิงประธานสภาเวท (46)
- ศึกสุดท้าย: ถ้าเป็นมิตรและปลุกมังกรไว้ มังกรทองลดพลังราหุลกาฬ 7–12 และเดรโกมาเป็นพันธมิตร ถ้าเข้าสภาเงา จะยืนข้างราหุลกาฬ (+12)
- บทส่งท้ายของเดรโกตามความสัมพันธ์ และฉากพิกเซลใหม่ `magicDragon`
- เซฟ: เพิ่ม `storyV6From`; ชีวิตที่เล่นค้างจะเริ่มเจอฉากใหม่ตั้งแต่ตัวเลือกถัดไป
- ปรับกระดานสืบสวนให้ผู้เล่นคิดเอง: เอาเครื่องหมาย ✔/✘ สีเขียว/แดง การตัดผู้ต้องสงสัยออก ตัวนับ "ยังน่าสงสัย" และคำใบ้ "ช่วยตัดได้กี่คน" ออกทั้งหมด เหลือเพียงลักษณะของแต่ละคนกับรายการเบาะแส
